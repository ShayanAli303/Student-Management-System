# 🎓 Student Management System

A modern full-stack Student Management System built with Django (backend) and React (frontend). It manages students, teachers, classes, attendance, exams, and grades with role-based authentication and a clean UI.

---

## 🚀 Features

- Role-based login (Admin, Teacher, Student)
- Student, Teacher, and Class management
- Attendance tracking
- Exams and grades system
- Secure authentication system
- Responsive modern UI
- Clean and scalable architecture

---

## 🛠 Tech Stack

**Backend:**
- Django
- Django REST Framework
- SQLite

**Frontend:**
- React (Vite)
- JavaScript
- CSS

## ⚙️ Setup Instructions

### Clone Repo
``bash
git clone https://github.com/your-username/student-management-system.git
cd student-management-system

python -m venv venv
venv\Scripts\activate

cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_data
python manage.py runserver
